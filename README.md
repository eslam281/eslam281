## 👨‍💻 About Me

I'm a **Computer Science student and Flutter Developer** focused on building
maintainable, user-friendly, and scalable mobile applications.

My main focus is **Flutter and Dart**, with hands-on experience in:

- 📱 Flutter application development
- 🧩 BLoC & GetX state management

- 🌐 REST API integration and networking
